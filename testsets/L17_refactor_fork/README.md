# Level 17: Refactor Fork

**What it tests:** forks of refactoring paths. Multiple valid refactoring solutions for the same clone region.

This level contains clone regions with multiple semantically equivalent but structurally different implementations (e.g., the same logic expressed as a loop vs. recursion, or using different but equivalent API patterns), testing a detector's ability to recognize refactoring alternatives as clones.

**Status:** Complete. `detection_expectation`: varies by family.
