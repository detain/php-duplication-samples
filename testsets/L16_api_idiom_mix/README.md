# Level 16: API Idiom Mix

**What it tests:** multiple API idioms combined in a single set. Diverse API substitution patterns must all be recognized as equivalent.

This level combines multiple API idiom families (CF-*, API-*) into compound sets, where each cluster uses a different idiom and the detector must correctly identify all of them despite surface-level differences.

**Status:** Complete. `detection_expectation`: varies by family.
