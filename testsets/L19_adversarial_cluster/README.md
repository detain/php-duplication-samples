# Level 19: Adversarial Cluster

**What it tests:** multiple adversarial patterns combined. Anti-detection techniques applied together to challenge robust detectors.

This level applies multiple adversarial transforms (encoding tricks, layout obfuscation, token fragmentation, threshold probes) simultaneously, creating sets specifically designed to challenge detectors that have solved individual adversarial axes but not their combinations.

**Status:** Complete. `detection_expectation`: varies by family.
